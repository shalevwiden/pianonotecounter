# Blog thumbnails

Replace these PNG files to change cover images for the preset articles.
Keep the same filenames — the blog pages point at them directly.

| File | Article |
| --- | --- |
| `good-piano-habits.png` | Good piano habits |
| `practice-with-peak-notes.png` | Make piano fun / creators |
| `piano-history.png` | Piano history |
| `chopin.png` | Chopin story |

Recommended size: about **1600×1000** (16:10). JPG/WebP also work if you update the matching `<img src>` in `blog/index.html` and the article HTML file.
